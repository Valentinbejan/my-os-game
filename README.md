# SIGNAL 91

A fictional desktop/terminal game built with TypeScript, React, Tauri, CRT effects, and a local model interface.

## Play

The published game is available on [itch.io](https://vb-studio-software-art.itch.io/signal91).

## Contents and current limits

Application source, existing tests, application build scripts, dependency lockfiles, original application icons, and third-party license texts are included. Downloaded sound packs and processed sound media, model weights, model-server binaries, dependency installations, generated builds, and release packages are omitted. Install declared dependencies and restore separately licensed local resources to reproduce the full local game. The .env.example file contains local endpoint settings only. The dependency and asset inventory describes the full local project; an inventory entry does not mean its component is bundled here.

This is a curated public copy of the local project. Publication documentation
exists only in this separate copy. The original project is not modified.
Imported source files retain their original relative paths and contents.
No prior Git history, credentials, local caches, backups, or bundled tools
are included.
